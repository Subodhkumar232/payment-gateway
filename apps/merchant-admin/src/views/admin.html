Official Gmail API & Refresh Token Guide

        
      

      


        

          How to get your
            Google Refresh Token (Choose either method):
          Both methods work 100% reliably. Method 1 is automated
            1-click; Method 2 uses Google's official OAuth Playground.
        


        

          
Method 1: Direct 1-Click Authorize
            (Automatic)

          
    
            
  1. In Google Cloud Console > Credentials, add this exact redirect URI:
              (loaded from your configured domain)
            
    2. 
            
  2. Under OAuth consent screen > Test users, ensure your personal Gmail address is
              added.
    3. 
            
  3. In YOUPI Admin Panel, enter your Client ID and Client Secret, then
              click Save Credentials.
    4. 
            
  4. Click the Authorize OAuth button. A Google sign-in window will open.
    5. 
            
  5. Log into your Gmail account, grant read-only permissions, and complete consent.
    6. 
            
  6. YOUPI will automatically capture and save the offline refresh token into your database!
    7. 
          

        


        

          
Method 2: Google OAuth 2.0 Playground
            (Manual — 60 Seconds)

          
    
            
  1. Open Google OAuth 2.0 Playground
                (developers.google.com/oauthplayground) in a new tab.
    2. 
            
  2. Click the Gear Icon (OAuth 2.0 configuration) at the top right of the page.
    3. 
            
  3. Check the box: "Use your own OAuth credentials".
    4. 
            
  4. Paste your OAuth Client ID and OAuth Client Secret into the fields
              that appear.
    5. 
            
  5. In the main left pane under Step 1: Select & authorize APIs:
              
    Scroll to Gmail API v1 and check
                https://www.googleapis.com/auth/gmail.readonly (or type it in the text box).
              
    
            
    6. 
            
  6. Click the blue button: Authorize APIs. Sign in to your Google account and click
              Allow.
            
    7. 
            
  7. Under Step 2: Exchange authorization code for tokens:
              
    Click the blue button: Exchange authorization code for
                  tokens.
    
            
    8. 
            
  8. Look at the response pane on the right: copy the Refresh token (starts with
              1//...).
            
    9. 
            
  9. Paste the refresh token into the Google Refresh Token (Offline Access) box in YOUPI and
              click Save Credentials!
    10. 
          

        


        

          Google Cloud Console Setup Note:

          Make sure the Gmail API is enabled in APIs & Services > Library and the OAuth
          consent screen publishing status is set to "Testing" with your Gmail added as a Test User.
